How to read these changes

An added module is a new entry in the selected released Library. Updated records can reflect changes to source code, an explanation or a recorded module state. A removed entry is absent from that snapshot; this does not by itself invalidate its mathematics.

These counts do not count new theorems or prove scientific novelty. Layout movement and website changes do not contribute to them.
