Trureturing Upload

Trureturing Upload is a local publishing tool operated for the Omega Institute YouTube channel. It synchronizes numbered TRURETURING film releases to the channel authorized by its owner.

The tool uses Google OAuth and the YouTube Data API to identify the authorized channel, check its existing videos, upload films, set thumbnails, and manage the visibility of those uploads. Authorization is required because an API key alone cannot publish videos to a YouTube channel.

This tool is for the operator's own channel. It has no public registration or sign-in service. Channel access is granted through Google's consent page; the tool does not ask for a Google password.

应用说明

Trureturing Upload 是用于 Omega Institute YouTube 频道的本地发布工具。它在频道所有者授权后，将《真理回返》影片按编号同步到频道，核对已有内容以避免重复上传，并设置封面和视频可见性。

Google 授权用于确认频道和执行上述操作。此工具只供运营者自己的频道使用；没有公开注册服务，也不收集 Google 账号密码。
