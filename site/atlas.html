What this map measures

This view shows the released library's module dependencies. A starting point has no prerequisites inside this published graph; it may still use Mathlib or other external foundations. Downstream counts measure module reuse, not the number of theorem applications or a universal measure of mathematical importance.

Every arrow shown is an actual module dependency. The overview selects highly reused modules and connecting paths; search includes every released module. Field labels describe where modules are reused and do not determine the graph layout.
