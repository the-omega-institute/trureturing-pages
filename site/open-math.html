DEFINITION · INFORMATION ESCAPETRURETURING

Information escape:
what our readings cannot tell apart.

Readout q
what we can observe about a state
Question T
what we want to know about it
Escape
two states with the same readout but different answers

E(q, T) = { (x, y) : q(x) = q(y), T(x) ≠ T(y) }

No escape means the readout already answers the question.

Define it before using it. A readout is any way of observing; the question is what we need to know. The escape set is every pair of states the readout merges although the question separates them. It is the exact place where a problem is still open.
THE ENGINETRURETURING

A definition is worth
the escape it cuts.

E(q ∨ d, T) = E(q, T) ∩ ker d

Add a definition d: only the pairs it also cannot separate still escape. What remains is the next question. If nothing we can define sees it, we change the language.

This identity is the centre of our Definition-Escape Completion Theory: adding a definition intersects the escape set with what that definition cannot distinguish. Research becomes a loop: find the escape, define, let the kernel check, measure what still escapes.

THE FILTERTRURETURING

No new distinction,
no new theorem.

✕

Bind-only

Renaming, restating or repackaging what is already proved.

✓

New distinction

A step no existing result can supply: a new object, construction or estimate.

Bind-only work is useful reuse, but we do not count it as a new theorem. New work has to cut an escape: a new fact on its live proof path. That expected contribution is named before the attempt and stays visible in the record.
