03 / DEFINITION AND ESCAPETRURETURING

A definition is worth the escape it cuts.

Hard problems rarely need a longer path through known theorems. They need a new definition that separates what was mixed together. The object does not change; the structure that describes it does.

WHERE A QUESTION IS STILL OPEN

E(q; T) = ker q ∖ ker T

Pairs the current readout q cannot tell apart, although the question T needs them apart.

WHAT A NEW DEFINITION DOES

E(q ∨ d; T) = E(q; T) ∩ ker d

Adding a definition d cuts the open set by intersection. When nothing escapes, the question is decided.

WHEN TO CHANGE LANGUAGE

E ∩ KΓ ≠ ∅

If what remains is invisible to every available definition, more search cannot succeed. Change the language.

EVERY NEW THEOREM ANSWERS

Definition-Escape Completion Theory (DECT) in the theory volumes; Lean: EscapePairs, ExactRate, StructuralNovelty, LayerChain. The escape judge is under development: its findings are warnings, not admission gates.

Say it plainly: we look for definitions. A definition earns its place by the escape it removes. When the remaining escape is blind to every definition we have, we change the language instead of grinding. The four questions are how every new theorem registers its escape.

05 / TRIVIAL OR NOTTRURETURING

A wrapper adds no information. We refuse it.

A new theorem that only instantiates, projects or repackages what is already proved is bind-only: it creates no new distinction, so it earns no place in the library.

BIND-ONLY · REJECTED
  • Instantiating an existing theorem
  • Projecting or packaging conjuncts
  • Rewriting, renaming, normalizing with simp or ring

Example: a general theorem restated at n = 60 is closed by citing the general theorem.

CONTENT · ADMITTED
  • An escape witness on the live proof path
  • A statement the existing results cannot yield by those steps
  • Or a conclusion produced by a real construction or estimate

Example: a five-element semigroup no existing result provides.

DECLARED BEFORE THE ATTEMPT

The expected new fact is pre-registered, so it cannot be relabeled afterwards. One exception: settling a named, published open problem counts by itself, with its verbatim source registered first.

Triviality is judged in review against an exact definition, and the kernel checks correctness. Mention the open-problem exception honestly: the semigroup case on slide 11 is bind-only in proof shape and admitted because it settles a named problem.

08 / THE HARNESSTRURETURING

The kernel judges truth. The harness keeps everyone honest.

✓

Machine checks

  • The Lean kernel: no sorry, only approved axioms.
  • The same required checks for everyone, human or agent.
  • Frozen records expose any change to a verified statement.
↗

Review of meaning

  • Does the formal statement match its source?
  • Is it content, or only a wrapper?
  • Is every claim proved, refuted, open or marked assumed-unverified?
THE METHOD CHECKS ITSELF

The rules every agent reasons by are themselves frozen theorems: appending to the record never changes an old settlement; a lookup table fits the past with zero loss yet commits to no prediction; more budget cannot remove a blind residual.

No gate waits for a person to decide right or wrong. People choose what is worth asking.

Correctness, faithfulness and value are separate questions. The kernel settles the first; review handles the other two, and can make mistakes.
