# In-graph Concept Lens

The Mathematical Atlas is the primary human research surface. Selecting a node does not navigate away from the graph. It opens a release-bound Concept Lens beside the 3D structure.

## Human path

```text
3D Atlas
  -> select a concept
  -> Concept: what it says, why it matters, documents
  -> Relations: local directed dependency graph and exact upstream/downstream lists
  -> Research: open the release-bound CMA workspace intentionally
```

The static Knowledge Library remains available for durable links, immutable release views, search indexing, and no-WebGL fallback. It is not the main exploration path.

## Relation authority

The lens keeps relation classes separate:

| Class | Meaning | Used in local proof DAG |
|---|---|---|
| certified | truth dependency from the release | yes |
| authored | Blueprint or narrative relation | no |
| derived | deterministic structural affinity | no |
| advisory | Intuition or CMA candidate | no |

Spatial proximity and structural affinity never become proof dependencies. The local 2D DAG contains certified directed edges only.

## Exposition authority

The Concept panel uses the following order:

1. Blueprint-authored abstract;
2. Blueprint-authored theorem label;
3. explicit path-derived fallback stating that authored exposition is unavailable.

No browser model invents mathematical exposition. Every document card identifies its provenance.

## Structural explanations

`Why it matters` translates already-published exact metrics into readable statements:

- descendant count becomes downstream support;
- direct in/out degree becomes immediate prerequisites and next steps;
- adjacency to open dependents becomes frontier proximity;
- high dependency betweenness becomes bridge load;
- high descendant cost becomes downstream dependency footprint.

Raw values and exact release coordinates remain in a collapsed `Audit details` section.

## Local exploration

Relations supports one-hop and two-hop neighborhoods. The local view is bounded to 48 nodes and has an equivalent keyboard-accessible relation list. Following a local node focuses the same concept in the global 3D Atlas.

## Research workspace

The Research Console is a hidden drawer. It opens only after a user chooses a research action. The selected node continues to be published through `#node-detail[data-node-id]`, preserving the existing exact-release Research, Intuition writeback, and Formalize handoff contracts.

CMA remains disabled by deployment configuration until separately activated. The Atlas, Concept Lens, local DAG, documents, and static Library work without CMA.

## Deferred structure work

This change does not claim a final mathematical conformation. The current renderer still uses the legacy browser force layout. The next releases add:

1. deterministic `pages-conformation.v1` coordinates;
2. `topology-atlas.v1` clusters, boundaries, roles, and affinities;
3. clustered 3D rendering and semantic zoom;
4. two-node and two-cluster comparison;
5. `pages-research-context.v2` structural selections.
