# trureturing identity

The mark is an original ligature of two lowercase `t` forms. A shared rail, two descending strokes and rounded continuations echo branches and joins in the Atlas. Mint carries the primary stroke; pale ink carries the second. The small terminal dot gives the mark a consistent endpoint at favicon sizes. This is a brand symbol, not a depiction of a particular theorem or certified graph.

- `site/assets/brand-mark.svg`: self-contained 80 × 80 vector, including a dark rounded tile. Used in the primary header, Atlas heading and homepage favicon. The file is 516 bytes and requires no JavaScript or font download.
- `site/assets/brand-lockup.svg`: horizontal wordmark for dark backgrounds, with the institute name. The wordmark uses the existing Arial/Helvetica family.
- Mint: `#78dfc8`; ink: `#e2f2ee`; tile: `#101b20`; border: `#30484d`.
- Header: 32 px desktop / 28 px mobile. Atlas heading: 48 px desktop / 38 px mobile. Keep the mark's square aspect ratio and at least one quarter of its width clear around standalone applications.

Shared site styling uses the mark for generated and static page headers. The Atlas keeps an explicit decorative image alongside its accessible text brand. The homepage requests the updated shared stylesheet with a version parameter so the previous text badge does not persist in the CDN cache.
