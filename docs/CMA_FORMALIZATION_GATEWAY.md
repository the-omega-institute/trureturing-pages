# CMA formalization gateway

Pages binds each conversation and formalization request to an exact truth release, certified topology, optional Topology Atlas, and Pages conformation.

The user flow is:

```text
select structure
-> chat with CMA
-> run the formalization-worth gate
-> choose GitHub-attributed or anonymous contribution
-> explicitly approve repository work
-> submit through the CMA gateway
```

GitHub authorization is handled by the gateway session. Pages does not store access tokens, personal access tokens, or caller-supplied GitHub identities.

The anonymous route queues accepted work for the TrueTurning service identity. Both routes preserve the exact research-context digest and gate receipt.

A gate acceptance authorizes an attempt. It does not establish mathematical truth. Certification still requires the normal Formalize, review, Base admission, and truth-release pipeline.
