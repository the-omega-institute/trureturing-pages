# Interface languages

The public site defaults to English. `assets/i18n.mjs` provides an English / 中文
selector in the shared header. A supported `?lang=` parameter takes precedence
over the saved browser preference; otherwise the preference or English is used.
There is no automatic locale selection from the browser's system language.

The initial Chinese dictionary covers shared navigation, selected interface
labels and the complete curated Millennium research maps, including the 93 RH
formulations. Other authored prose falls back to English. Source excerpts,
Lean code, mathematical identifiers, evidence receipts, API records and user
notes keep their original content. This is interface localization, not a claim
that all research papers or the entire upstream corpus have been translated.

Use canonical English in HTML and JSON. Add exact text translations to
`site/assets/locales/zh-CN.json`. For a dynamic message, use explicit placeholders:

```js
import { t, ready } from './i18n.mjs';
await ready;
const label = t('{0} specifications · {1} families', specifications, families);
element.textContent = label;
```

The shared DOM adapter translates exact text nodes and accessible labels, and
handles dynamically added UI. It never performs substring or HTML replacement.
Mark verbatim excerpts with `data-i18n-original` or `translate="no"`; code,
preformatted text, math, editable content and textareas are already excluded.
Translate graph display data before measuring or wrapping labels. The curated
Millennium data adapter explicitly limits translation to display fields and
catalogue titles; IDs, paths, status enums and source pins remain unchanged.
Never use a translated message as a storage flag or program condition.

Language switching reloads the current URL while preserving its query parameters
and hash, so graph selection, release coordinates and filters survive. Owned HTML
links carry the selected language. External links, APIs and proof downloads keep
their original URLs. Archived Wiki redirects also retain the language query.
When storage is unavailable the URL still works. If a dictionary cannot load,
the page remains usable in English with a short visible notice.

To add another language, register its code and native label in `LOCALES`, add the
corresponding JSON dictionary and run the tests below. Missing keys always fall
back to English.

```sh
python -m unittest tests.test_millennium
node --test tests/js/i18n.test.mjs
# Requires a generated HTTP preview and Playwright with Chrome:
node tests/browser/i18n.cjs
node tests/browser/header-alignment.cjs
```

The browser test checks all seven maps, all 93 RH node routes, default-language
text, switching, notes, mobile layout, unavailable storage/dictionaries and
rendered internal destinations. Set `ATLAS_ORIGIN` to test a deployed site.
